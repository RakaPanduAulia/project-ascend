# Project Ascend

App glow-up gamifikasi — papan misi harian ala RPG. Centang misi, EXP naik, (nanti) level & stat ikut naik. Terinspirasi app "66日間".

Tema warna: Sung Jin-Woo (Solo Leveling) — gelap + biru elektrik.

## Status
- **Tahap 1 (sekarang):** papan misi + EXP bar, disimpan di browser (localStorage).

## Cara buka
Buka `index.html` di browser. Gak perlu install apa-apa.

## Struktur
- `index.html` — struktur halaman
- `style.css` — tampilan (tema gelap biru)
- `app.js` — logika (misi, EXP, level, simpan data)
